# 蘇清的音乐专辑 / SuQing's Music Albums

2026-11-03 已公开发布：[创意工坊 3832881848](https://steamcommunity.com/sharedfiles/filedetails/?id=3832881848) · [Git 源码](https://github.com/suching8848/suqing-music-albums)。上传回调与公开查询已核验；发布状态与个人安装及游戏内验收分别记录。 音乐实际听感、僵尸反应及新美术显示仍待用户验收。

单人扩展，Mod ID `SuQingMusicCollections`，版本 1.1.0，适用 B42.21，依赖当前 True Music B42（`truemusic`，工坊 3397198968）。展示名改为“蘇清的音乐专辑”，目录、Mod ID、物品 ID 和 schema 1 均保持不变。复用已安装的四个音乐包及其原始 Ogg 音源；不包含、下载或重编码音源，不修改 Workshop 原件。来源和权利范围见 [NOTICE.md](NOTICE.md)，英文说明见 [README.en.md](README.en.md)。

已适配的音乐包为 GIRLS BAND CRY（3554671997）、Poppin'Party（3585009083）、MyGO!!!!! / Ave Mujica（3585014312）、Roselia（3654879576），另识别基础主题曲磁带和黑胶。按需安装并启用想使用的音乐包，缺少的包不会提供其歌曲及可刷新的精选集；不自动导入其他任意 True Music 音乐包。现有 `Codex_TrueMusic_Headphones_4221` 为可选兼容子补丁，当前上游组合的离线回归分别覆盖启用和未启用两种情况。

## 获取及操作

- **完整精选专辑**：八个多曲艺人／合作组，每组磁带和黑胶各一盘，共十六种。沿现有普通音乐磁带／黑胶的刷新表添加对应介质的作者精选，包括普通容器、junk、传统分发表及车辆分发表。继承该刷点同作者／同介质原单曲的单件有效权重（同类型重复登记先合并，再取单件均值）；没有该作者原单曲时，沿用该介质单件均值。不加概率倍率或上限，不按曲数放大，不改原单曲条目或权重，不回填已搜索容器。
- **已有单曲整理**：在角色背包内多选至少两首同介质的不同单曲，右键“整理所选单曲为合集…”。作者不限，可混合乐队与主题曲。先预览投入列表，确认并完成动作后才消耗单曲。磁带和黑胶分开。收藏、已装备、重复曲目或不属于角色的物品不参与。
- **拆回**：自制合集右键“拆回原投入单曲…”，可还原投入的类型、耐久、自定义名称和可序列化 ModData。预制精选集不可拆出全套单曲。取消或材料移走时不提交交换。
- **放入播放器**：沿用原设备操作面板的插入／弹出功能。原有单曲继续保留。
- **歌单控制**：打开原“设备选项”，歌单自动作为同窗内默认展开的折叠模块出现。原“设备选项与歌单”入口也激活同一窗口。右键松散合集只读预览。车内右键背包物品可打开车载设备选项与歌单。支持选择歌曲、上下首、停止，以及顺序一次、列表循环、单曲循环和每轮不重复的随机播放。关闭界面不停止音乐。

同作者合集顶部显示作者名；混搭显示“自制专辑”，曲目行补充艺人名。所有成品及自制合集按单张原版磁带／黑胶重量，目前均为 0.02，曲目数量不增加重量。旧版 schema 1 合集、插入设备的侧录和拆回来源继续沿用，无需直接编辑存档。

## 标题编码与显示

1.0.0 的生成器直接写入 Unicode Lua 字符串，与本机 Kahlua 字符串词法读取不兼容，曾把“二息歩行”截成“oiL”、把“影色舞”截成“qr”和控制字符。1.1.0 使用安全 UTF-8 字节转义，并用独立原文 UTF-8 oracle 检查真实运行字符串，涵盖歌名和艺人名。

实际启用的汉化字体覆盖全部 289 个原歌名和 14 个原艺人名；中文界面优先显示原文，不替换全局字体。数据另保留经过校对的中文阅读名用于回退。音轨 ID 与音源不变。

合集的实体载体与当前曲目声音 ID 分离；四槽设备分别保存歌单、曲序、模式和投入来源。插入、弹出时完整传递；音频句柄只在本次游戏运行中存在，不写入存档。重新读档后应暂停，保留曲目和模式；不提供精确秒数续播或进度拖动。

## 收听与声音

随身听（包括旧单曲）及接耳机的随身播放器走本地 2D 音频别名：自己可听，不创建公共 `now_play` 记录，不发送引怪 `addSound`，不通过角色／世界发射器播放。需要耳机的设备仍要求插耳机；摘耳机、关机、取电池、丢弃或角色死亡时停止。自动保存不打断正在播放的歌曲。普通音箱未接耳机以及地面音响、车载保持外放与相应引怪规则。

别名直接引用当前音频文件，保持源增益。静音或缺少别名时不会退回外放路径。游戏内实际声音、僵尸反应和设备交互由用户验收；离线测试是代码及受控边界证据。

## 曲目范围

目录映射 289 条曲目，按实际演唱艺人／合作组合归类。默认预制合集不含两段 MyGO 访谈。`PPP75` 上游声音定义指向不存在的 `PPP100.ogg`，当前标记不可用，不擅自猜测替换音频；该物品仍保留，避免数据丢失。其余单曲和合作组仍可原样收听，有足够同组曲目时可手工合并。

`tools/build_catalog.py --check` 检查已审阅目录、生成文件与 26 个上游元数据文件的哈希。上游更新后须审阅，再使用 `--import-local` 更新目录；不要盲目重建覆盖人工归类。

## 验证和停用

`tools/run_tests.py` 使用当前游戏 JAR 的 Kahlua 编译器/运行时及原生序列化，加载生产代码和实际 True Music 源码，以受控的设备／库存／音频接口进行行为回归。报告在 `validation`，具体范围以报告为准。未启动游戏、未进入正式档。

停用前先从设备弹出所有合集，把自制合集拆回单曲，避免自定义载体或设备侧录在禁用后无法识别。预制合集为新物品；禁用后不保证保留。正常退出后分别移除新档默认名单和目标存档名单中的本 Mod ID，保留原有顺序。当前 Headphones 本地补丁及原音乐包不变。
